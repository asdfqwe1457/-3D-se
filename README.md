第一期学员学习路线：角色设计 + 美宣插画如何同步进阶
第一期学员里问得最多的一个问题：角色设计和美宣插画，到底该先学哪个？分开学怕脱节，一起学怕贪多嚼不烂。带完第一期全程后我可以明确回答：这两件事不但不冲突，而且必须同步进阶——角色设计是美宣插画的骨，美宣插画是角色设计的肉，拆开学，两边都长不完整。下面把第一期验证过的学习路线完整拆开讲。

第一阶段：打共同地基，先把“造型”这件事练通。 前三周不分科目，只练两样东西：剪影和体块。每天画十个角色剪影，只涂黑，要求闭眼能读出体型和职业；每天搭五个体块组合，只画盒子，要求朝向和穿插站得住。这一阶段角色设计和美宣共用同一套练习，因为两者对造型的要求完全一致——剪影不清、体块不稳，不管做设计还是画插画都会翻车。第三周末做一次测试：用自己最满意的剪影加体块，画一张简单单色稿，检验地基牢不牢。同步进阶的第一步不是学两门课，是把两门课的共同地基打到最硬。

第二阶段：角色设计领跑，美宣插画跟跑。 第四到第六周以角色设计为主：练符号化设计、比例夸张、配色系统、焦点控制，每周出一个完整角色设定。美宣插画这一阶段只做一件事：把每周的角色设定转成一张简单的氛围稿——固定机位、简单光影、不加复杂背景。这一步的关键是让学员体会“设定能不能撑起一张画”：设计阶段偷懒的符号化，画成插画立刻暴露；插画阶段画不出的味道，说明设计阶段没想清楚。这一阶段的目的是让设计和插画开始互相校验。

第三阶段：美宣插画领跑，角色设计跟跑。 第七到第九周反过来：以美宣为主，练构图、光影氛围、镜头语言、材质表现，每周出一张完整插画。角色设计这一阶段做配套工作：为插画补细节设定、补配件说明、补多角度视图。这一步会让学员发现，画插画时缺的设计信息，就是角色设计该补的功课；而设计时没考虑过的光影和视角，正是插画阶段的价值。两边轮换领跑，才知道彼此缺什么。同步进阶的秘诀不是平均用力，是轮换领跑、互相补位。

第四阶段：合并输出，做完整作品。 第十到第十二周，每个学员产出套作品：一张完整角色设定表加一张同角色的美宣插画。设定表按符号化、配色系统、多视图、配件说明四项检查；插画按构图、光影、材质、氛围四项检查。最后一周做交叉评审：把设定表和插画并排看，检查是不是同一个角色、同一个气质、同一个世界。对不上的地方，就是下一轮要补的弱项。合并输出是检验同步进阶成不成功的唯一标准。

三条来自第一期的经验教训。第一，前两周最容易被质疑“为什么不教设计也不教插画”，但地基不牢，后面两样都会长歪。第二，轮换领跑阶段最容易贪心，两边都想多做，结果两边都半吊子，路线要求每周只准一门领跑，另一门只做配套。第三，合并输出阶段一定要留足三周，设定和插画的对齐比想象中耗时。

角色设计和美宣插画不是两条路，是一条路的两段：设计负责想清楚，插画负责画到位。同步进阶的核心不是同时学两门课，而是让两者始终互相校验、轮换推进。第一期走完这条路线，学员最大的变化不是画技涨了多少，而是脑子里有了“设计和插画是一体”的意识。这个意识，比任何单项技巧都值钱。
